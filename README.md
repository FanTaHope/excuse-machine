# 🎰 Excuse Machine

> **[한국어 README](README.ko.md)**

> I did this for a reason. Let us prove it.

A fun side project / test app that generates officially certified excuses for any action you type in.

Certified by the International Excuse Certification Authority (IECA). No refunds. No rebuttals.

![preview](assets/preview.png)

## 🔗 Try it now

**[https://fantahope.github.io/excuse-machine](https://fantahope.github.io/excuse-machine/)**

## How it works

1. Type in an action (e.g. exercise, studying, going to work)
2. Pick "Reason I can't" or "Reason I should"
3. Get an officially stamped excuse card
4. Save it as an image or share it with friends

## Features

- 🌏 **4 Languages** — Korean, English, Japanese, Chinese
- 🎴 **Excuse Cards** — Officially stamped and sealed, obviously
- 📸 **Save / Share** — Download as image or copy to clipboard

## Tech Stack

Pure HTML / CSS / JavaScript. No frameworks. No bundlers. Just open the file and go.

## Run locally

```bash
git clone https://github.com/FanTaHope/excuse-machine.git
cd excuse-machine
npx http-server -p 3000
```
