# 🎰 핑계 자판기

> **[English README](README.md)**

> 내가 이러는 데는 다 이유가 있어. 우리가 증명해줄게.

행동을 입력하면 공인된 핑계를 발급해주는 웹 서비스입니다.

국제핑계인증원(IECA) 공인. 반박 시 무지개반사.

![preview](assets/preview.png)

## 🔗 바로 써보기

**[https://fantahope.github.io/excuse-machine](https://fantahope.github.io/excuse-machine/)**

## 이런 겁니다

1. 행동 입력 (예: 운동, 공부, 출근)
2. "못 하는 이유" 또는 "해야 하는 이유" 선택
3. 그럴듯한 핑계가 적힌 공식 인증 카드 발급
4. 카드를 이미지로 저장하거나 공유 가능

## 기능

- 🌏 **4개 국어 지원** — 한국어, English, 日本語, 中文
- 🎴 **카드 생성** — 공인 도장이 찍힌 핑계 카드 발급
- 📸 **이미지 저장 / 공유** — 캡처해서 친구한테 보내세요
- 🔒 **안전 필터** — 위험한 입력에 대한 보호 장치 내장
- 💾 **언어 기억** — 새로고침해도 선택한 언어 유지

## 기술 스택

순수 HTML / CSS / JavaScript. 프레임워크 없음. 번들러 없음. 그냥 파일 열면 됨.

## 로컬에서 실행
